# AGENTS.md

Rules for AI agents working in this repository.

1. **Do not make any pushes.** Never run `git push` (including force pushes) or otherwise publish commits to a remote. The user pushes manually.
2. Do not add AI/agent attribution (e.g. `Co-Authored-By` trailers) to commits.
3. Do not rewrite history (amend, rebase, reset) without explicit instruction.
4. Keep the `venv/` virtual environment out of version control; it is listed in `.gitignore`.
